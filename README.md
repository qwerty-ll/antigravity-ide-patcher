# ⚡ Universal Antigravity Patcher (Windows / macOS / Linux)

Универсальный 1-клик патчер для снятия региональных блокировок в экосистеме Google Antigravity:
* **Antigravity IDE** (редактор кода)
* **Antigravity 2.0** (десктопный менеджер / `language_server.exe`)
* **Antigravity CLI** (`agy.exe`)
* **Google Antigravity Extension для VS Code**

---

## 🪟 Инструкция для Windows (1 клик, всё автоматически)

**Устанавливать Python НЕ нужно** — скрипт работает на стандартном Windows PowerShell и автоматически определяет любую установленную версию.

### Как запустить:

1. **Скачайте репозиторий**:
   * Нажмите зеленую кнопку **Code** вверху страницы ➔ **Download ZIP**.
   * Распакуйте ZIP в любую папку (например, на Рабочий стол).
2. **Закройте Antigravity**, если программа открыта.
3. **Запустите файл [`patch.bat`](patch.bat)** двойным кликом:
   * *Если Windows SmartScreen покажет синее окно:* нажмите «Подробнее» ➔ «Выполнить в любом случае».
4. **Скрипт всё сделает сам**:
   * Автоматически найдет, что именно у вас установлено (**Antigravity IDE**, **Antigravity 2.0**, **CLI** или **VS Code**).
   * Завершит мешающие фоновые процессы.
   * Создаст безопасные резервные копии исходных файлов (`.bak`).
   * Пропатчит все найденные компоненты и очистит кэш.
   * Запишет весь процесс в файл журнала **`patch.log`**.
5. **Запустите Antigravity** и выполните вход в аккаунт!

---

## 🛡️ Бэкапы и откат назад

* **Автоматический бэкап**: Перед любым изменением скрипт создает `.bak`-файлы всех компонентов.
* **Откат в 1 клик**: Чтобы вернуть оригинальное состояние, просто запустите **[`restore.bat`](restore.bat)**.
* **Диагностика (`patch.log`)**: Если возникли какие-либо трудности, откройте файл **`patch.log`** рядом со скриптом — там поминутно расписан каждый шаг.

## 🍎 Использование на macOS / Linux (через Python)

Если вы используете macOS или Linux:
```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите патчер
python3 main.py
```
