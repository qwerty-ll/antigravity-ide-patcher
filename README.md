# ⚡ Antigravity IDE Patcher (Windows / macOS / Linux)

Утилита для быстрого снятия региональных ограничений в **Google Antigravity IDE** (`isGoogleInternal -> true`) без необходимости использовать VPN.

---

## 🪟 Инструкция для Windows (1-клик, без Python)

Для запуска на Windows **не требуется устанавливать Python или сторонние библиотеки** — всё работает через встроенный Windows PowerShell.

### Быстрый старт:

1. **Скачайте этот репозиторий**:
   * Нажмите зеленую кнопку **Code** вверху страницы ➔ **Download ZIP**.
   * Распакуйте скачанный ZIP-архив в любую удобную папку (например, на Рабочий стол).
2. **Закройте Antigravity IDE**, если программа запущена.
3. **Запустите файл [`patch.bat`](patch.bat)** двойным кликом мыши.
   * *Если появится предупреждение SmartScreen:* нажмите «Подробнее» ➔ «Выполнить в любом случае».
4. **Скрипт автоматически**:
   * Найдет путь установки Antigravity IDE (в `%LOCALAPPDATA%`, `Program Files` или реестре Windows).
   * Завершит фоновые процессы IDE при необходимости.
   * **Создаст резервную копию** исходного файла (`main.js.bak`).
   * Заменит проверку `isGoogleInternal` на `true`.
   * Очистит кэш скомпилированного кода (`CachedData` и `Code Cache`).
   * Сохранит подробный журнал выполнения в файл **`patch.log`**.
5. **Запустите Antigravity IDE** и войдите в свой аккаунт Google!

---

## 🛡️ Безопасность, бэкапы и логи

* **Автоматический бэкап**: Перед внесением любых изменений создается резервная копия `main.js.bak` в папке установки.
* **Откат в 1 клик**: Если вы захотите вернуть все назад, просто запустите файл **[`restore.bat`](restore.bat)**.
* **Логгер ошибок**: Все шаги, найденные пути и ошибки подробно записываются в файл **`patch.log`** рядом со скриптом. Если что-то пойдет не так, откройте этот файл или отправьте его для диагностики.

## ❓ Частые вопросы и ошибки

**1. Ошибка: «Не удалось автоматически найти Antigravity IDE»**  
Скрипт предложит ввести путь вручную. Обычно Antigravity IDE на Windows устанавливается по пути:  
`C:\Users\<ВашеИмя>\AppData\Local\Programs\Antigravity IDE`  
Просто скопируйте этот путь в окно консоли и нажмите Enter.

**2. Ошибка 400 Bad Request / User location is not supported**  
Если при запросах после патча появляется ошибка 400, это означает, что Google детектирует локацию на уровне сети. Рекомендуется использовать специальные DNS (например, Xbox DNS / GeoHide) или сменить аккаунт.
